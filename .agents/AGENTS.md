# Codebase Style Rules

## Typography and Punctuation
- **No Em-Dashes**: Never use the em-dash (`—`) symbol in the codebase (neither in code, metadata, strings, nor comments).
- **Alternatives**:
  - In copy/text, use standard hyphens (`-`), commas, colons, or restructure the sentence to make it flow naturally.
  - In signature or blockquote attributions, use en-dashes (`–`) or hyphens (`-`).
  - In comments, use standard hyphens (`-`) or colons (`:`).
